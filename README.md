# 创作放映室 · 雨城与视觉实验

[打开作品总入口](https://howyoungx.github.io/rainlight-creative-portfolio/) · [视频目录](videos.html) · [下载全部非视频资料](https://github.com/howyoungx/rainlight-creative-portfolio/releases/download/nonvideo-v1/NonVideo_Materials.zip)

公开保存本次创作的说明、剧本、海报、换装图片、分镜原画、声音试听、3D 模型、计时表及验收记录。

- 《雨城最后一束光》：同一原创故事，10 种艺术风格，各 5 分钟，配套 10 张宣传海报。
- Higgsfield：同一 S14 包扎情节，5 个模型的 6–10 秒试映样片，共约 46 秒。五部五分钟云端影片尚未启动；样片共使用 410 积分。
- 海报与换装：初版和细化版共 40 张，保留 A/B 对比。
- ComfyUI 功能演示：图生视频、文生视频、海报、草图转场景、换装、装修、贴纸、图片转 3D。
- 声音试听：Piper、Serena、Vivian 三种声音的三句对照；正式影片使用本地 Qwen3-TTS Serena。

视频上传至作者的 YouTube 频道 Haoyang，设为“凭链接观看”。本公开仓库中的观看链接可供持有链接的人访问。仓库及非视频下载包不包含 MP4；中间镜头与重复原始样片不作为独立作品上传。
